## What the script does ##

Automates Keyence BZ-X800 image stitching end-to-end:

* Stitches every image folder containing a .gci file using the Keyence BZ-X800 Analyzer and Wide Image Viewer.
* Exports each acquired channel **and** the overlay as separate TIFFs, reproducing the manual Keyence workflow (no post-processing by default).
* Optionally applies **Auto Level Correction** (Auto + Apply in the Wide Image Viewer) per channel before export.
* Lets you name outputs in bulk — typed, auto-incremented, or pasted straight from a tracking spreadsheet.
* **Resumes** safely: folders whose output already exists are detected and skipped.
* Organizes output into **per-mouse subfolders** for acquisitions that span multiple slide holders.
* Optionally merges channels into a composite and adds scale-bar/metric information via Fiji/ImageJ, and compresses copies of the raw folders.

## Software requirements ##

* [Autohotkey version 1.x](https://www.autohotkey.com/) (Open source) — **not** v2, the syntax is incompatible
* [Keyence Analyzer Analysis Software, incl. stitching add-on](https://www.keyence.com/landing/microscope/lp_fluorescence.jsp) (Proprietary)
* [Fiji/ ImageJ](https://imagej.net/Fiji) (Open source) — only needed when the ImageJ merge option is enabled
* [7-zip](https://www.7-zip.org/download.html) (Freeware) — only needed when compression is enabled

## Acquisition conditions ##

* Microscope: Keyence BZ series
* Software: BZ-X800 Viewer
* Image type: Still image
* Sample holder: Slide
* Channels: CH1, DAPI; CH2, GFP; CH3, RFP; CH4, Brightfield. The filename labels are configurable in the Setup GUI; the underlying channel order is set on the microscope.
* Overlay: Deactivated, later generated by the Analyzer software if multiple channels were used for acquisition
* Capture method: Multi-Color (Single color can be acquired via _Multi-Color_ setting)
* Capture area settings: Multi-Point supported

## Using the script ##

Double-click **run-instructions\runStitch.ahk**. Two GUIs walk you through a run; the last-used settings persist to `settings.ini` in the install folder.

### 1. Setup GUI ###

* Pick the **input** folder (the script processes its subfolders, up to 4 levels deep, that contain a .gci file) and the **output** folder (anywhere).
* **Channels** — tick which channels (and the overlay) to export, like checking the boxes when stitching manually.
* **Auto Level Correction** — tick which of those channels should be auto-leveled in the Wide Image Viewer before export.
* **Channel labels** — set the filename label for each channel (e.g. `gfp` → `cFos`, `rfp` → `EGR`).
* **Per-mouse subfolders** — route each section into `<output>\<prefix>` by the name text before the first `_` (see below).
* **ImageJ merge** — off by default (separate channel files). When on, channels are merged into a composite in Fiji.

### 2. Naming GUI ("Name Your Images") ###

Assign the output name for each detected folder. Three ways:

1. **Paste names…** — paste the output-name column straight from your tracking spreadsheet. The name column is auto-detected (a header row is ignored) and names are applied to the folders top-to-bottom. This is the primary workflow.
2. **Type a name** per row, optionally using **Fill below** to auto-increment a trailing `_NN` down the list.
3. Leave a row **blank to skip that folder**.

The panel scrolls for long sessions. **Only named folders are stitched** — leaving folders blank is the simple way to re-run a session in which some folders are already done. Before launching, a summary confirms how many folders will be stitched and how many are skipped (unnamed or already-stitched).

## File name handling ##

* Files are written under their final name directly, so a run cancelled partway still leaves correctly named output.
* Channel-dependent extensions: CH1, `_DAPI`; CH2, `_GFP`; CH3, `_RFP`; CH4, `_BF`; Overlay, `_Overlay` (these labels are configurable in the Setup GUI).
* Output name `<name>_<label>.tif`, e.g. `M23_A_01_DAPI.tif`.

### Per-mouse subfolders ###

The Keyence has three slide holders, so a single acquisition folder can hold sections from several mice. With **per-mouse subfolders** enabled, each section is written to `<output>\<prefix>`, where the prefix is the name text before the first `_` (e.g. `M23_A_01` → `<output>\M23`, `M22_D_01` → `<output>\M22`). Point the Setup output at the **base** folder (e.g. `…\Stitched`).

### Multi-Point name handling ###

The microscope allows the user to image up to three slides in one run (Multi-Point acquisition).
When using Multi-Point acquisition, however, only one common name can be entered in the Capture-window (example: myExp).
The Analyzer output for three slides that are imaged together is the following:
A folder _myExp_ that contains up to three subfolders, _XY01_, _XY02_, _XY03_. The names XY01-3 correspond to the position of the slides in the slide holder.

__This script allows the user to define up to three slide names by using _#_.__

___Example:___
Slide positions XY01-3 are used. Slide names can be specified individually if these names are preceeded by the _#_ symbol.

__Script output for three imaged slides, example shown for slide 2:__

__Input option 1.__ Common name entered, __myExp__. Output for slide 2: __myExp\_slide2__
__Input option 2.__ Common and slide names entered, __myExp#Cond1#Cond2#Cond3__. Output for slide 2: __myExp\_Cond2__
__Input option 3.__ Slide names entered, __#Apples#Pears#Oranges__. Output for slide 2: __Pears__

__Error handling:__ If an unrecognized input name, e.g. the subfolder name _XY04_ appears, the output name generated with _Input option 2_ would be _myExp#Cond1#Cond2#Cond3\_XY04_.

## Installation ##

To stitch images with this script the Keyence BZ-X800 Analyzer software needs to be installed, including the locally plugged USB dongle that enables Keyence's stitching add-on. If the installation is for some reason incomplete, the _Load a Group_ button will not respond and stitching is not possible.
Autohotkey is required; Fiji/ImageJ and 7-zip are only needed if you enable the ImageJ-merge or compression options.

### Set up ###

* Download this script and save it to a folder. This will be your installation folder, for example:
```
C:\Tools\AutoStitch-Keyence\
```
* Edit __ahkStitch.ahk__, set the path to the installation folder (lines 6 and 9) and to the external programs (the `options["keyenceAnalyzer"]`, `options["imageJ"]` and `options["gzip"]` lines in `getDefaultOptions()`):
```
6   STITCH_BASE_DIR := "C:\Tools\AutoStitch-Keyence\"
9   #include C:\Tools\AutoStitch-Keyence
...
    options["keyenceAnalyzer"] := "C:\Program Files\Keyence\BZ-X800\Analyzer\BZ-X800_Analyzer.exe"
    options["imageJ"] := "C:\Program Files\fiji-imageJ\Fiji.app\ImageJ-win64.exe"
    options["gzip"] := "C:\Program Files\7-Zip\7zg.exe"
```
* Edit __run-instructions\runStitch.ahk__, set the path to the installation folder (line 3):
```
3   #include C:\Tools\AutoStitch-Keyence\ahkStitch.ahk
```

All three paths must be updated together when moving the installation.
